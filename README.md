Low configuration Wrapper Renderer

>基于LTW渲染器的变体，专注于给低配设备提供更好的渲染性能

本分支基于原始项目[LTW渲染器](https://github.com/MojoLauncher/LTW)

>与原版的主要区别

对渲染器部分重写，去除低端机不需要的函数优化对低端机的体验
已知支持兼容
MakeUp-UltraFast-9.4a
LITE shaders 4.9 
mellow
(其他的低端机玩起来也卡卡的没必要兼容)

>一堆废话

通过优化渲染管线、精简冗余计算逻辑、改进光影与材质的处理算法、适配硬件底层特性并合理调度算力资源等核心手段，从研发侧降低渲染器的开发迭代成本、后期维护成本以及跨平台适配成本，从运行侧大幅减少设备的GPU/CPU算力占用、内存与显存的消耗，降低对硬件配置的要求，同时显著提升渲染的帧速率、画面加载速度，优化光影还原度、材质精细度等视觉表现，让渲染器在更低的硬件资源投入下，实现更流畅的运行效果和更优质的画面输出
