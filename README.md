## MobileGlues Module for Pojavlauncher 
Running OpenGL ES 3.1 on mind, primarily intended for running Minecraft.

# Building
`./gradlew:MobileGlues:assembleRelease`

After completion, an AAR with native libraries will be available in `MobileGlues/build/outputs/aar/MobileGlues-release.aar`
